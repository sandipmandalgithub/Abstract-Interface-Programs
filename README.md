# Java Abstract Class and Interface Programs

This repository contains Java programs demonstrating **Abstract Classes and Interfaces** in Object-Oriented Programming (OOP).

These programs were created to practice and understand abstraction, inheritance, implementation, and polymorphism in Java.

## 📚 Concepts Covered

### Abstract Classes

* Abstract classes
* Abstract methods
* Concrete methods in abstract classes
* Extending abstract classes
* Implementing abstract methods
* Inheritance

### Interfaces

* Interface declaration
* Interface implementation
* Implementing multiple interfaces
* Interface methods
* Multiple inheritance using interfaces
* Polymorphism with interfaces

## 🔑 Key Concepts

* Abstraction
* Inheritance
* Polymorphism
* Abstract Classes
* Interfaces
* Method Implementation

## 🛠️ Technologies Used

* **Programming Language:** Java
* **IDE:** Eclipse IDE
* **Concept:** Object-Oriented Programming

## 🚀 How to Run

1. Clone or download this repository.
2. Open the Java source files in Eclipse IDE or another Java IDE.
3. Open the desired Java class.
4. Run the program as a Java Application.

## 🎯 Purpose

This repository was created for Java programming practice and to strengthen my understanding of **Abstract Classes, Interfaces, Abstraction, Inheritance, and Polymorphism** in Java.
